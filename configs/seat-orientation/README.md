# Seat Orientation Configuration

This folder will contain **only verified, service-specific** orientation mappings after Phase 0/6 evidence is available. Never add a universal seat-number rule here.

Each future mapping must identify:

- source/evidence ID from `docs/DATA_AND_EVIDENCE_REGISTRY.md`;
- train service and direction;
- class and coach identifier/layout version;
- inclusive seat-number ranges;
- forward/backward/neutral orientation;
- verification date and confidence;
- expiry/recheck condition.

Owner-provided heuristics belong in `docs/ASSUMPTION_REGISTER.md`, not in a live configuration.
