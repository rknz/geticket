# UI Direction

The extension should feel calm, compact, modern and trustworthy rather than like a trading dashboard or automated bot.

## Visual principles

- Clean cards, restrained colour palette, clear typography, generous spacing
- Light and dark themes; Bangla and English text must both remain legible
- Strong status language: Live, Checked at, Stale, Unavailable, Challenge paused, Unsupported
- Responsive desktop dashboard and touch-friendly Android layout
- Minimal motion; no misleading countdowns or fake real-time activity

## Required views

Overview, New Journey Search, Results, Alternative Routes, Monitoring Center, Ticket Release Planner, Notifications, Data Source Status, Security & Privacy, and Settings.

## Important UX states

Loading, no result, source unavailable, stale result, browser feature unsupported, monitoring paused, and user action required must each have an explicit state and plain-language explanation.
